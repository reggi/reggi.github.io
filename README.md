# reggi.github.io

reggi's static Webcard collection at https://reggi.github.io/.
Generated by the versioned [webcard-site template](https://github.com/reggi/webcard-site).
Every card is rendered into HTML for search engines and visitors without JavaScript.

## Add a card

Run **Actions → Add webcard** with a public URL, or:

```sh
gh workflow run add-webcard.yml -R reggi/reggi.github.io \
  -f url=https://reggi.github.io/journal-calendar/
```

Existing cards are reused without fetching. Set `refresh=true` to capture again
and preserve history. Archives and collection order live in `cards/`.
Customize `site.config.json` and `theme.css`; Knitto updates leave those files
and the cards unchanged.

```sh
npm ci
npm run dev
npm run check
```

See the upstream README for format limits, authenticated dispatch, themes,
browser checks, and reviewed template upgrades.

## Migration and rollback

The prior project-directory homepage and its metadata-sync automation were
replaced deliberately. The remote `pre-webcard-site` tag preserves commit
`bc4493eb073e6caaab581aec877de9402e67ef75`.

To roll back, revert the migration and any later gallery-only commits through
a reviewed change, restoring that tagged application's files and workflows.
Verify the old build before deployment; do not force-push or run competing Pages
workflows. Saved Webcards can be backed up separately before rollback.
